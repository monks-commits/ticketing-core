📊 Звіти

Офіційні форми, робочі звіти квиткового відділу та аналітика VA. Тут залишаємо тільки те, що має сенс для поточного рівня системи.

Обов’язкові форми

Базові звіти квиткового господарства для АСПК: щоденний касовий звіт, зведений звіт по сеансу, видача та повернення квитків розповсюджувачам.

КГ-13

КГ-13 — щоденний касовий звіт

Звіт касира за день. Перший обов’язковий звіт для касової зміни.

КГ-10

КГ-10 — зведений звіт по сеансу

Підсумковий звіт по заходу. Має привести систему до формули: видано − повернуто = реалізовано.

КГ-7

КГ-7 — видача квитків

Накладна на видачу квитків комісіонеру / розповсюджувачу. Зараз працює через розділ “Комісіонери” в обороті квитків.

КГ-8

КГ-8 — повернення квитків

Накладна на повернення нереалізованих квитків від комісіонера / розповсюджувача. Зараз працює через розділ “Комісіонери”.

V2

КГ-12 — акт списання / закриття залишків

Майбутній звіт для закриття нереалізованих / погашених залишків після завершення сеансу.

КГ-1 / КГ-2 / КГ-5 / КГ-6 / КГ-9 / КГ-11 поки не виносимо в робочий інтерфейс: для нашого електронного контуру першочергові КГ-10, КГ-13, КГ-7, КГ-8.

Операційні звіти VA

Те, що з’явилося в системі додатково: VA-квота, компенсаційний борг, контроль доступу та реальний оборот квитків.

VA

VA-квота / випуск

Скільки місць випущено в оборот VA, скільки продано, заброньовано, повернуто та залишилося.

борг

Компенсаційний борг

Створені компенсації, погашені компенсації, залишок боргу театру, звідки виникло та де погашено.

контроль

Контроль доступу

Звичайні проходи, компенсаційні проходи, повтори, інциденти та стан входу по сеансу.

броні

Броні / комісіонери

Старий звіт “Бронювання” більше не відображає повну логіку. Актуальна робота ведеться через оборот квитків та картку комісіонера.

Аналітика та перевірка

Не бухгалтерські форми, а перевірочні та управлінські звіти: канали продажу, системні дії, аудит, CSV.

channels

Продажі по каналах

Канали продажу, суми, середній чек, явка, ціни та типи квитків. Не дублює директорські “Продажі”, а працює як перевірочний звіт.

audit

Журнал контролю та системних дій

Сканування, повтори, службові події, компенсаційні дії та інші записи аудиту.

пізніше

Продажі по майданчиках

Поки приховано з робочого контуру. Повернемо, коли буде стабільна мультиплощадочна аналітика.

Розділ “Звіти” тепер не дублює директорський дашборд і не повторює кухню квиткового відділу. Тут залишаються офіційні форми, друковані звіти та перевірочні журнали.
