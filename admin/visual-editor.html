Публікація

Social Connector площадки. Visual Editor може відправити власний visual без «Рекламного відділу».
Оригінальна афіша не змінюється. Для Facebook VA створює окрему соціальну копію. Натискання на афішу у Facebook відкриває конкретний сеанс на вітрині майданчика. Якщо у сеансу є Live Poster — він запускається на вітрині; якщо немає — глядач бачить звичайну афішу.
Відкрити публікацію у Facebook
Facebook отримує клікабельну link-картку. Оригінальна афіша не змінюється: VA створює окрему соціальну копію з підказкою. Токен у браузер не передається; підключення Facebook Page належить майданчику.
